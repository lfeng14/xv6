#### 描述
Add a system call to xv6 that returns the amount of free memory available.

#### 实现
- 启动xv6 on mac:
  ```
  git clone git@github.com:mit-pdos/xv6-public.git
  brew install i686-elf-gcc # install cross compiler chain
  make
  make qemu
  ```
