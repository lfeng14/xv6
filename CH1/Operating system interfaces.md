# Chapter 1: Operating system interfaces

## 概述

操作系统的职责是在多个程序之间共享计算机，并提供比硬件本身更有用的服务集。操作系统管理和抽象底层硬件，使字处理器无需关心使用的是哪种磁盘硬件。操作系统在多个程序之间共享硬件，使它们同时运行（或看起来同时运行）。最后，操作系统提供受控的程序交互方式，使它们可以共享数据或协同工作。

## 核心概念

### 内核与进程

- **内核（Kernel）**：一个特殊的程序，为运行中的程序提供服务
- **进程（Process）**：每个运行中的程序，包含内存（指令、数据、栈）
- **用户空间（User space）**：进程执行的空间
- **内核空间（Kernel space）**：内核执行的空间

### 系统调用（System calls）

进程调用系统调用来请求内核服务。系统调用进入内核，内核执行服务后返回。

## 1.1 进程和内存

### 进程结构

xv6进程由以下组成：
- **用户空间内存**：指令、数据、栈
- **内核私有状态**：每个进程在内核中的私有状态

### 分时共享（Time-sharing）

xv6在等待执行的进程集合之间透明地切换可用的CPU。当进程不执行时，xv6保存进程的CPU寄存器，下次运行时恢复它们。

### 进程标识符（PID）

内核为每个进程关联一个进程标识符（PID）。

### fork系统调用

- 创建新进程，新进程是调用进程的内存的精确副本（指令和数据）
- 在原始进程和新进程中都返回
- 原进程中返回新进程的PID
- 新进程中返回0
- 父进程和子进程拥有相同的内存内容，但执行时使用独立的内存和寄存器

### exit系统调用

- 使调用进程停止执行
- 释放内存和打开文件等资源
- 接受整数状态参数，通常0表示成功，1表示失败

### wait系统调用

- 返回当前进程已退出（或被杀死）的子进程的PID
- 将子进程的退出状态复制到传递给wait的地址
- 如果调用者的子进程都没有退出，wait等待一个子进程退出
- 如果调用者没有子进程，wait立即返回-1

### exec系统调用

- 用从文件系统存储的文件加载的新内存映像替换调用进程的内存
- 文件必须有特定格式（ELF格式），指定文件的哪部分保存指令、哪部分是数据、从哪条指令开始等
- 成功时不返回给调用程序，而是从ELF头中声明的入口点开始执行加载的指令
- 接受两个参数：包含可执行文件的文件名和字符串参数数组

### sbrk系统调用

- 运行时需要更多内存的进程（可能用于malloc）可以调用sbrk(n)将其数据内存增长n字节
- 返回新内存的位置

## 1.2 I/O和文件描述符

### 文件描述符（File descriptor）

- 小整数，表示进程可以读写的内核管理对象
- 进程可以通过打开文件、目录或设备，或创建管道，或复制现有描述符来获得文件描述符
- 文件描述符接口抽象了文件、管道和设备之间的差异，使它们看起来都像字节流
- xv6内核内部使用文件描述符作为每个进程表的索引，因此每个进程都有从0开始的私有文件描述符空间

### 标准文件描述符约定

- 文件描述符0：标准输入（standard input）
- 文件描述符1：标准输出（standard output）
- 文件描述符2：标准错误（standard error）

### read和write系统调用

- `read(fd, buf, n)`：从文件描述符fd读取最多n字节，复制到buf，返回读取的字节数
- `write(fd, buf, n)`：从buf写n字节到文件描述符fd，返回写入的字节数
- 每个引用文件的文件描述符都有一个关联的偏移量
- read从当前文件偏移量读取数据，然后按读取的字节数推进该偏移量
- write在当前文件偏移量写入数据，然后按写入的字节数推进该偏移量

### close系统调用

- 释放文件描述符，使其可以被未来的open、pipe、dup等系统调用重用

### dup系统调用

- 复制现有文件描述符，返回引用同一底层I/O对象的新文件描述符
- 两个文件描述符共享一个偏移量

## 1.3 管道（Pipes）

- 管道是向进程公开的小内核缓冲区，作为一对文件描述符，一个用于读取，一个用于写入
- 向一端写入数据使数据可用于从另一端读取
- 提供了进程之间通信的方式

### 示例：管道通信

```c
int p[2];
char buf[128];
pipe(p);
if(fork() == 0) {
    close(0);
    dup(p[0]);  // stdin = p[0]
    close(p[0]);
    close(p[1]);
    exec("/bin/wc", argv);
} else {
    close(p[0]);
    write(p[1], "hello world\n", 12);
    close(p[1]);
}
```

## 1.4 文件系统

### 文件系统调用

- `chdir`：改变当前工作目录
- `mkdir`：创建新目录
- `mknod`：创建设备文件
- `link`：创建指向同一文件的多个名称（硬链接）
- `unlink`：删除文件（仅当链接计数为零时才真正删除）

### 目录条目

目录包含条目，每个条目都是一个链接。每个目录至少包含两个条目："."（当前目录）和".."（父目录）。

## 1.5 现实世界

Unix系统调用接口已经非常成功，现代操作系统（BSD、Linux、macOS、Solaris，甚至Microsoft Windows）都有类似Unix的接口。
