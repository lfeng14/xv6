  ---                                                                                                                                                                                                                                               
  xv6 启动流程详解                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                    
  第一阶段：BIOS 引导（硬件初始）                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                    
  计算机加电后发生的事情：                                                                                                                                                                                                                          
  1. CPU 重置为实模式（16位，只能访问1MB内存）                                                                                                                                                                                                      
  2. BIOS 从固定地址 0xFFFF0 开始执行                                                                                                                                                                                                               
  3. BIOS 做硬件自检（POST），初始化基本设备                                                                                                                                                                                                        
  4. BIOS 从启动盘的第一个扇区（512字节，引导扇区）加载到物理地址 0x7C00                                                                                                                                                                            
  5. 跳转到 0x7C00 开始执行                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                    
  ---                                                                                                                                                                                                                                               
  第二阶段：bootasm.S — 从实模式到保护模式                                                                                                                                                                                                          
                                                                                                                                                                                                                                                    
  这是引导扇区的第一部分，做了以下关键事情：                                                                                                                                                                                                        
  ```                                                                                                                                                                                                                                                  
  ┌──────┬──────────┬─────────────────────────────────────────────────────────────────────────────────────────────────────────┐                                                                                                                     
  │ 步骤 │ 代码位置 │                                                 做什么                                                  │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 1    │ cli      │ 关中断                                                                                                  │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 2    │ 16-19行  │ 清零数据段寄存器 DS、ES、SS                                                                             │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 3    │ 23-37行  │ 开启A20地址线 —— 这是历史遗留，早期PC为了兼容8086把第21根地址线锁死在0，需要手动开启才能访问1MB以上内存 │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 4    │ 42行     │ lgdt gdtdesc —— 加载临时GDT（全局描述符表）                                                             │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 5    │ 43-45行  │ 设置 CR0 的 PE 位，进入保护模式                                                                         │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 6    │ 51行     │ ljmp $(SEG_KCODE<<3), $start32 —— 长跳转刷新流水线，真正进入32位模式                                    │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 7    │ 56-62行  │ 设置保护模式下的数据段寄存器                                                                            │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 8    │ 65行     │ 设置栈指针 esp = $start（向下生长）                                                                     │                                                                                                                     
  ├──────┼──────────┼─────────────────────────────────────────────────────────────────────────────────────────────────────────┤                                                                                                                     
  │ 9    │ 66行     │ call bootmain —— 调用C代码                                                                              │                                                                                                                     
  └──────┴──────────┴─────────────────────────────────────────────────────────────────────────────────────────────────────────┘                                                                                                                     
  ```                                                                                                                                                                                                                                                  
  临时GDT（79-87行）：                                                                                                                                                                                                                              
  - 空描述符（必须）                                                                                                                                                                                                                                
  - 代码段：基址0，限长4GB，可读可执行                                                                                                                                                                                                              
  - 数据段：基址0，限长4GB，可读写                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                    
  这时是对等映射（虚拟地址=物理地址）。                                                                                                                                                                                                             
                                                                                                                                                                                                                                                    
  ---                                                                                                                                                                                                                                               
  第三阶段：bootmain.c — 加载内核ELF                                                                                                                                                                                                                
                                                                                                                                                                                                                                                    
  bootmain() 的任务是从磁盘读取内核ELF文件到内存：                                                                                                                                                                                                  
  ```                                                                                                                                                                                                                                                  
  ┌──────┬─────────┬──────────────────────────────────────────────────────────┐                                                                                                                                                                     
  │ 步骤 │  代码   │                           说明                           │                                                                                                                                                                     
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 1    │ 25行    │ 把 0x10000 作为临时空间                                  │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 2    │ 28行    │ readseg 读取第一页（4KB）到 0x10000 —— 这里包含ELF头     │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 3    │ 31-32行 │ 检查 ELF magic (0x7F454C46)                              │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 4    │ 35-42行 │ 遍历程序头表，把每个段加载到指定物理地址                 │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 5    │ 39行    │ readseg(pa, filesz, off) —— 从磁盘offset读filesz字节到pa │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 6    │ 40-41行 │ 如果 memsz > filesz，多余部分填0（bss段）                │
  ├──────┼─────────┼──────────────────────────────────────────────────────────┤
  │ 7    │ 46-47行 │ 跳转到ELF入口点 entry()（不再返回）                      │
  └──────┴─────────┴──────────────────────────────────────────────────────────┘
  ```
  磁盘读取（readsect）：
  - 通过IO端口 0x1F0-0x1F7 操作IDE硬盘
  - 一次读一个扇区（512字节）
  - 内核从扇区1开始（扇区0是引导扇区自己）

  ---
  第四阶段：entry.S — 开启分页，跳转到高地址

  现在执行的是内核的ELF入口 entry()：
  ```
  ┌──────┬─────────┬────────────────────────────────────────────────────┐
  │ 步骤 │  代码   │                        说明                        │
  ├──────┼─────────┼────────────────────────────────────────────────────┤
  │ 1    │ 47-49行 │ 设置 CR4 的 PSE 位，开启4MB大页                    │
  ├──────┼─────────┼────────────────────────────────────────────────────┤
  │ 2    │ 51-52行 │ movl $(V2P_WO(entrypgdir)), %cr3 —— 加载临时页目录 │
  ├──────┼─────────┼────────────────────────────────────────────────────┤
  │ 3    │ 54-56行 │ 设置 CR0 的 PG 位，开启分页                        │
  ├──────┼─────────┼────────────────────────────────────────────────────┤
  │ 4    │ 59行    │ 设置栈 esp = stack + KSTACKSIZE                    │
  ├──────┼─────────┼────────────────────────────────────────────────────┤
  │ 5    │ 65-66行 │ jmp *%eax —— 间接跳转到 main()                     │
  └──────┴─────────┴────────────────────────────────────────────────────┘
  ```
  临时页表 entrypgdir（main.c 102-108行）：
  // 虚拟地址 [0, 4MB)  -> 物理地址 [0, 4MB)
  // 虚拟地址 [KERNBASE, KERNBASE+4MB) -> 物理地址 [0, 4MB)
  KERNBASE=0x80000000，所以此时：
  - 0x80100000（内核链接地址）映射到 0x00100000（物理地址）
  - 跳转 main() 后，EIP 变成高地址了

  ---
  第五阶段：main.c — 内核初始化主流程

  这是最关键的部分，一步步初始化各个子系统：
  ```
  ┌──────┬────────────────────────────────┬──────────────────────────────────────┐
  │ 顺序 │              函数              │                做什么                │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 1    │ kinit1(end, P2V(4MB))          │ 初始化物理页分配器（只管理前4MB）    │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 2    │ kvmalloc()                     │ 创建内核页表（完整的，不再是临时的） │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 3    │ mpinit()                       │ 检测多处理器（有几个CPU）            │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 4    │ lapicinit()                    │ 初始化本地APIC（中断控制器）         │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 5    │ seginit()                      │ 设置本CPU的GDT和段寄存器             │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 6    │ picinit()                      │ 禁用旧的8259 PIC（用IOAPIC代替）     │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 7    │ ioapicinit()                   │ 初始化IOAPIC                         │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 8    │ consoleinit()                  │ 初始化控制台                         │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 9    │ uartinit()                     │ 初始化串口                           │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 10   │ pinit()                        │ 初始化进程表锁                       │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 11   │ tvinit()                       │ 初始化中断向量表（IDT）              │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 12   │ binit()                        │ 初始化块缓存                         │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 13   │ fileinit()                     │ 初始化文件表                         │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 14   │ ideinit()                      │ 初始化磁盘                           │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 15   │ startothers()                  │ 启动其他AP CPU（见下文）             │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 16   │ kinit2(P2V(4MB), P2V(PHYSTOP)) │ 初始化剩余物理内存                   │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 17   │ userinit()                     │ 创建第一个用户进程 init              │
  ├──────┼────────────────────────────────┼──────────────────────────────────────┤
  │ 18   │ mpmain()                       │ 进入调度器，开始运行进程             │
  └──────┴────────────────────────────────┴──────────────────────────────────────┘
  ```
  ---
  启动其他 CPU（startothers）

  xv6支持多处理器，BSP（引导CPU）要把其他AP（应用CPU）拉起来：

  1. 把 entryother.S 的代码复制到物理地址 0x7000
  2. 为每个AP分配一个栈
  3. 通过APIC发送INIT-SIPI-SIPI序列启动AP
  4. AP执行 entryother.S → 进入 mpenter()
  5. mpenter() 里切换到内核页表，初始化，然后也进入 mpmain()
  6. BSP等待所有AP都设置 started=1 后继续

  ---
  第一个用户进程（userinit）

  userinit() 创建第一个进程（pid=1）：
  1. 分配进程结构 proc[0]
  2. 设置页表，映射内核
  3. 分配用户内存，把 initcode.S 复制进去
  4. 设置 trapframe，让它"好像"从用户态中断进来
  5. 设置 eip = 0（initcode的入口）

  initcode.S 做一件事：调用 exec("/init", argv)，执行 /init 程序。

  init.c 则创建控制台，打开标准输入/输出/错误，然后 fork 出 sh，从此系统就可以用了。

  ---
  最后：调度器（scheduler）

  mpmain() 调用 scheduler()，这是一个死循环：
  void scheduler(void) {
    for(;;) {
      sti(); // 开中断
      // 找一个 RUNNABLE 进程
      // 切换到它（swtch）
    }
  }

  从此，内核不再以"主线程"方式运行，只在中断/系统调用时执行，平时都是用户进程在跑。

  ---
  完整流程图总结
  ```
  加电
   ↓
  BIOS → 加载引导扇区到 0x7C00
   ↓
  bootasm.S (16位→32位保护模式)
   ↓
  bootmain.c (读磁盘ELF→加载内核)
   ↓
  entry.S (开启分页→跳高地址)
   ↓
  main.c (初始化各子系统)
   ├─ kinit1 → kvmalloc
   ├─ mpinit → lapicinit
   ├─ consoleinit
   ├─ ...
   ├─ startothers (启动其他CPU)
   ├─ userinit (创建第一个进程)
   ↓
  scheduler() (开始调度进程)
   ↓
  init进程 → exec("/init") → sh
   ↓
  系统就绪！
  ```
  推荐配合 bootasm.S:1、bootmain.c:18、entry.S:45、main.c:18 这几个入口点对照看。
